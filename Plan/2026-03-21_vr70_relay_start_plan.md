# Подключение частотника VR70 к плате конвейера через реле

## Задача
Минимальная задача:
- подключить частотник VR70 к плате конвейера через сухой контакт;
- обеспечить запуск двигателя от платы конвейера;
- минимальный сценарий: запуск на 5 минут, затем остановка.

## Что подтверждено по мануалу VR70
По руководству частотника:
- есть дискретные входы `DI1`, `DI2`, `DI3`, `DI4` и клемма `COM`;
- дискретные входы показаны как управление через сухой контакт в режиме `NPN`;
- по умолчанию `DI1` = прямое вращение;
- режим управления частотником можно перевести на клеммы;
- источник задания частоты можно оставить с панели управления с сохранением после отключения питания.

Из мануала:
- стр. 27-28: описание клемм управления и схема подключения дискретных входов;
- стр. 33: `P0-04` — режим управления с панели / клемм / RS-485;
- стр. 34: `P0-06` — выбор источника основной частоты;
- стр. 35: `P0-11` — задание частоты с панели управления;
- стр. 44: `P5-00` — функция `DI1`, по умолчанию `1 = прямое вращение`;
- стр. 46: `P5-13` — тип сигнала входов `DI`.

## Выбор пинов на плате конвейера
По текущей распиновке конвейерной платы:
- `PIN_RELAY_1 = GPIO21`
- `PIN_RELAY_2 = GPIO22`

Для минимального запуска частотника предлагаю:
- `GPIO21` — команда пуска частотника;
- `GPIO22` — оставить в резерве.

## Почему именно так
Для минимального сценария нужен только один сухой контакт:
- замкнули контакт — двигатель запустился;
- разомкнули контакт — двигатель остановился.

Второй релейный канал пока лучше не занимать.
Его можно оставить на будущее под:
- отдельный `Стоп`;
- `Сброс аварии`;
- другой внешний сигнал.

## Какой вход частотника использовать
Для минимального варианта использовать:
- `DI1`
- `COM`

Причина:
- `DI1` по умолчанию уже настроен как `прямое вращение` (`P5-00 = 1`);
- не нужно сразу менять много параметров.

## Схема подключения через реле
Ниже схема именно для сухого контакта.
Никакое напряжение с ESP32 на клеммы частотника подавать нельзя.
На частотник идут только контакты реле.

### Управление релейным модулем от платы конвейера
```text
Плата конвейера ESP32                Релейный модуль
---------------------                --------------
GPIO21  ---------------------------> IN1
GND     ---------------------------> GND
5V/3.3V ---------------------------> VCC   (зависит от вашего модуля реле)
```

### Сухой контакт реле к частотнику
```text
Релейный модуль                      Частотник VR70
--------------                      --------------
COM  ------------------------------> COM
NO   ------------------------------> DI1
NC   -- не использовать
```

### Логика работы
```text
Реле выключено:
NO разомкнут
DI1 и COM не соединены
Частотник стоит

Реле включено:
NO замкнут с COM
DI1 соединен с COM
Частотник получает команду прямого вращения
```

## Важная проверка перед подключением
На схеме в мануале входы показаны для режима `NPN`.
Нужно проверить положение аппаратной перемычки выбора `NPN/PNP` на частотнике.

Для предложенной схемы исходное допущение такое:
- частотник настроен как в схеме мануала для `NPN`;
- сухой контакт между `DI1` и `COM` является рабочей командой.

Если перемычка стоит в `PNP`, схему нужно перепроверить перед подачей команды.

## Какие параметры выставить на частотнике для минимального запуска
### Обязательно
1. `P0-04 = 1`
   - управление с клемм

2. `P0-06 = 1`
   - основная частота задается с панели и сохраняется после отключения питания

3. `P0-11 = нужная частота`
   - например сначала поставить небольшую безопасную частоту для проверки

### Обычно уже подходит по умолчанию
4. `P5-00 = 1`
   - `DI1 = прямое вращение`

### Рекомендация по безопасности
5. На первом пуске проверить, что никакие другие DI-входы не подключены случайно.

## Минимальный сценарий запуска на 5 минут
Логика на плате конвейера должна быть такой:

1. включить реле на `GPIO21`
2. удерживать его включенным `300000 мс`
3. выключить реле

То есть:
- `включить на 5 минут`
- `потом отпустить`

## Самый безопасный порядок пусконаладки
1. Сначала выставить на частотнике небольшую частоту.
2. Подключить только один релейный канал: `COM -> COM`, `NO -> DI1`.
3. Проверить мультиметром, что реле действительно просто замыкает контакт.
4. Кратко включить реле на 1-2 секунды.
5. Если двигатель стартует и останавливается правильно, переходить к команде на 5 минут.

## Что я рекомендую как итог
Для первой реализации:
- использовать `GPIO21` как команду пуска частотника;
- подключить реле сухим контактом между `COM` и `DI1`;
- `GPIO22` не занимать;
- на частотнике использовать:
  - `P0-04 = 1`
  - `P0-06 = 1`
  - `P0-11 = нужная частота`

Это минимальная и самая простая схема, чтобы запустить двигатель на 5 минут без участия мастера.
