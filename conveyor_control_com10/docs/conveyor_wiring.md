п# Электрические схемы конвейера

Документ фиксирует минимальные рабочие подключения, которые уже используются в проекте `conveyor_control_com10`.

## 1. Пуск основного отвода через реле и частотник VR70

Назначение:
- плата конвейера подает дискретную команду `ПУСК`
- реле замыкает вход `DI1` частотника на `COM`
- частотник запускает двигатель основного отвода

Условия на частотнике:
- `P0-04 = 1` - команда пуск/стоп с клемм
- `P5-00 = 1` - `DI1 = прямой ход`
- рабочая частота задается параметрами частотника

Схема:

```text
ESP32 плата конвейера                 Релейный модуль                Частотник VR70
---------------------                 ----------------               -------------------------
GPIO21  --------------------------->  IN1
GND     --------------------------->  GND
5V/3.3V --------------------------->  VCC

                                      COM  -------------------------> COM
                                      NO   -------------------------> DI1
                                      NC   не использовать
```

Логика:
- реле выключено -> `DI1` разомкнут с `COM` -> двигатель стоит
- реле включено -> `DI1` замкнут на `COM` -> двигатель запущен

Примечания:
- в проекте это `PIN_RELAY_1 = GPIO21`
- если используется типовой релейный модуль, чаще всего он `active LOW`
- силовые цепи двигателя и частотника в эту схему не входят

## 2. Старт запайщика через реле

Назначение:
- плата конвейера подает короткий импульс на вход `СТАРТ` запайщика
- реле играет роль сухого контакта

Схема:

```text
ESP32 плата конвейера                 Релейный модуль                Запайщик
---------------------                 ----------------               -------------------------
GPIO22  --------------------------->  IN2
GND     --------------------------->  GND
5V/3.3V --------------------------->  VCC

                                      COM  -------------------------> START_COM
                                      NO   -------------------------> START_IN
                                      NC   не использовать
```

Логика:
- плата включает реле на короткий импульс
- реле замыкает `START_IN` на `START_COM`
- запайщик получает команду старта

Примечания:
- в проекте это `PIN_RELAY_2 = GPIO22`
- длительность импульса сейчас задается в прошивке конвейера
- имена `START_COM` и `START_IN` условные: подставить реальные клеммы запайщика

## 3. Вход "цикл запайки завершен"

Назначение:
- запайщик сообщает плате конвейера, что цикл завершен
- сейчас в проекте принята логика `active LOW`

Рекомендуемая схема через сухой контакт:

```text
3.3V ---[4.7k..10k]---+-----------------> GPIO34  (вход платы конвейера)
                      |
                      +----o/ o----------> GND
                           контакт DONE
```

Логика:
- контакт разомкнут -> на `GPIO34` высокий уровень -> `DONE` не активен
- контакт замкнут -> `GPIO34` подтянут к `GND` -> `DONE` активен

Примечания:
- в проекте это `PIN_SENSOR_EXT_1 = GPIO34`
- `GPIO34` у ESP32 только вход
- у `GPIO34` нет внутренней подтяжки, поэтому внешний `pull-up` обязателен
- если запайщик выдает уже готовый дискретный сигнал, проверить совместимость по уровню с `3.3V`

## 4. Быстрая сводка рабочих подключений

```text
GPIO21 -> реле пуска основного отвода -> DI1/COM частотника VR70
GPIO22 -> реле старта запайщика
GPIO34 -> вход "цикл запайки завершен"
```

## 5. Что проверить перед первым пуском

1. Общая земля между ESP32 и релейным модулем
2. Правильный активный уровень релейного модуля
3. На VR70 установлен режим пуска с клемм, а не по RS-485
4. На входе `GPIO34` есть внешний `pull-up`, если приходит сухой контакт
5. На вход ESP32 не подается напряжение выше `3.3V`
