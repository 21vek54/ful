# Пины платы конвейера

Документ нужен как быстрая карта пинов проекта `conveyor_control_com10`.

Связанная документация:
- `docs/conveyor_wiring.md` - электрические схемы подключения

## Рабочие пины

| GPIO | Имя в коде | Назначение | Тип |
|---|---|---|---|
| 13 | `PIN_STEP_PUL` | Основной конвейер, STEP драйвера `DM542` | выход |
| 14 | `PIN_SHIFT_DIR` | Каретка сдвига, направление | выход |
| 23 | `PIN_SHIFT_PUL` | Каретка сдвига, STEP | выход |
| 33 | `PIN_SHIFT_SENSOR_Z` | Геркон каретки, край `Z` | вход |
| 25 | `PIN_SHIFT_SENSOR_C` | Геркон каретки, край `C` | вход |
| 27 | `PIN_FLAG` | Пневмоцилиндр флага | выход |
| 26 | `PIN_SENSOR` | Щелевой датчик тарелки | вход |
| 32 | `PIN_POS_PUL` | Позиционный двухручейковый конвейер, STEP | выход |
| 19 | `PIN_STEP2_PUL` | Двухручейковый отвод, STEP | выход |
| 21 | `PIN_RELAY_1` | Пуск основного отвода / частотника | выход |
| 22 | `PIN_RELAY_2` | Старт запайщика | выход |
| 34 | `PIN_SENSOR_EXT_1` | Вход `цикл запайки завершен` | вход, только вход |
| 16 | `PIN_RS485_RX` | Линия `SDA` локальной I2C-шины статуса | линия шины |
| 17 | `PIN_RS485_TX` | Линия `SCL` локальной I2C-шины статуса | линия шины |
| 18 | `PIN_RS485_DE_RE` | Резерв / бывший `DE+RE` | резерв |

## Резервные входы

| GPIO | Имя в коде | Назначение | Ограничения |
|---|---|---|---|
| 35 | `PIN_SENSOR_EXT_2` | Резервный вход 2 | только вход, без внутренней подтяжки |
| 36 | `PIN_SENSOR_EXT_3` | Резервный вход 3 | только вход, без внутренней подтяжки |
| 39 | `PIN_SENSOR_EXT_4` | Резервный вход 4 | только вход, без внутренней подтяжки |

## Пины, которые лучше не занимать

| Группа | Причина |
|---|---|
| `GPIO6..11` | подключены к встроенной SPI Flash |
| `GPIO1, GPIO3` | UART0, прошивка и лог по USB |
| `GPIO0, GPIO2, GPIO4, GPIO5, GPIO12, GPIO15` | загрузочные `strapping`-пины |

## Короткий вывод

- Универсальных свободных GPIO без конфликтов сейчас нет
- Для новых входов реально доступны только `GPIO35`, `GPIO36`, `GPIO39`
- Для новых выходов нужен либо пересмотр текущей раскладки, либо расширение платы
